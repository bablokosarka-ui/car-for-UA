# 🔧 НАЛАШТУВАННЯ АГЕНТА — покроково (~40 хв, один раз)

> Робіть кроки по порядку. Після кроку 6 система працює сама.
> Ключі НІКОЛИ не вставляйте в код чи чат — тільки в GitHub Secrets (крок 5) або локальний `.env`.

## Крок 1. Скринька відправника (5 хв)
1. Створіть окремий Gmail: напр. `4th.car.for.igor@gmail.com` (не особиста!)
2. Запишіть логін/пароль. З цієї скриньки підуть усі листи і відповіді журналістів

## Крок 2. Brevo (10 хв) — відправка email
1. Зайдіть на brevo.com → Sign up (на нову скриньку)
2. Підтвердьте email
3. Додайте відправника: **Senders → Senders & IP → Add sender** → вкажіть адресу з кроку 1 → підтвердьте листом
4. Отримайте ключ: **Profile (угорі праворуч) → SMTP & API → API Keys → Generate new key** → скопіюйте (починається з `xkeysib-`)

## Крок 3. Telegram-бот (5 хв)
1. У Telegram відкрийте **@BotFather** → `/newbot`
2. Ім'я: `4th Vehicle Fundraiser` · username: напр. `fourth_car_fund_bot`
3. Скопіюйте **токен** (вид `123456789:ABC...`)
4. Ваш chat_id: напишіть **@userinfobot** → він покаже ваш числовий ID

## Крок 4. Канал збору (5 хв)
1. Створіть канал (назва: «Четверта машина | На безпеку України», опис — у нотатці кампанії розд. 12.2)
2. **Налаштування каналу → Administrators → Add admin** → додайте свого бота → увімкніть «Post messages»
3. Запам'ятайте публічне посилання каналу (напр. `@chetverta_mashyna`) — воно і є chat_id каналу

## Крок 5. GitHub + ключі (10 хв)
1. Акаунт на github.com (якщо немає)
2. **New repository** → ім'я `igor-car-fund` → **Private** → Create
3. Додайте секрети: репо → **Settings → Secrets and variables → Actions → New repository secret**:
   | Name | Значення |
   |---|---|
   | `BREVO_API_KEY` | ключ з кроку 2 |
   | `SENDER_EMAIL` | скринька з кроку 1 |
   | `SENDER_NAME` | `Ihor's 4th Vehicle - Volunteer Fundraiser` |
   | `TG_BOT_TOKEN` | токен з кроку 3 |
   | `TG_CHAT_ID` | ваш числовий ID, кома, посилання каналу (напр. `123456789,@chetverta_mashyna`) |

## Крок 6. Завантажити код у репо (5 хв)
Варіант А (через мене): скажіть мені URL репо — я підготую git-команди, ви вставите і натиснете Enter (потребує встановленого Git).
Варіант Б (вручну): репо → **Add file → Upload files** → перетягніть УСІ файли з папки `fundraiser` (включно з папками `scripts`, `letters`, `.github` — у GitHub web папки створюються автоматично з відносних шляхів файлів).

## Крок 7. ТЕСТ (2 хв) — обов'язково
1. Репо → **Actions** → `daily-send` → **Run workflow**
2. У полі `test_email` вставте СВОЮ скриньку → Run
3. Перевірте пошту: вигляд листа, посилання, підпис
4. Потім `daily-report` → Run workflow → звіт має прийти вам у Telegram

## Крок 8. Запуск
- Розклад уже в коді: листи щодня 08:00–09:00 Києва, звіт +30 хв
- Заповніть `config.json` (ваше ім'я для підпису, ціль, зібрано)
- Додайте перші станції в `radio-tracker.csv` (я готую список хвилі 1 — скажіть «готуй список»)

## Щоденна рутина (після запуску)
- **09:00** — звіт у Telegram (вам + канал)
- Відповіді журналістів падають на скриньку з кроку 1 — пересилайте мені питання, я готую відповіді
- «no» у відповіді → впишіть `no` в колонку response трекера — агент більше не пише цій станції
- Раз на тиждень: оновіть `raised_ua` у config.json (цифра з баночки)

## Безпека
- Ключі — тільки в GitHub Secrets / локальний `.env` (зразок: `.env.example`)
- Ліміти: 10–15/день перші тижні, максимум 30 — інакше Brevo/Gmail заблокують
- Кожен лист має опт-аут; підпис — ваше реальне ім'я
